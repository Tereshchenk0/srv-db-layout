# Лабораторна робота №3: Поглиблений DQL в MySQL

Короткий опис виконання лабораторної роботи з написання аналітичних SQL-запитів до бази даних інтернет-магазину.

## Стек
- **СУБД:** MySQL
- **Інструмент:** DBeaver
- **Мова:** DQL

---

## Що реалізовано

* **Крок 1. Агрегатні функції:** підрахунок кількості товарів за категоріями (`COUNT`), розрахунок сумарної вартості складу (`SUM`), аналітика цін (`AVG`, `MIN`, `MAX`).
* **Крок 2. Групування (`GROUP BY` + `JOIN`):** розрахунок загальної суми покупок для кожного клієнта та сортування за витратами.
* **Крок 3. Фільтрація агрегованих даних (`HAVING`):** вибірка VIP-клієнтів із витратами понад 1000.
* **Крок 4. `INNER JOIN` (4 таблиці):** звіт за виконаними замовленнями (`Users` ↔ `Orders` ↔ `Order_Items` ↔ `Products`).
* **Крок 5. `LEFT JOIN`:** список усіх користувачів із відображенням замовлень (включно з клієнтами без покупок — `NULL`).
* **Крок 6. Підзапит (`Subquery` + `NOT IN`):** пошук товарів, які ще жодного разу не замовляли.
* **Крок 7. `UNION`:** комбінування імен клієнтів та назв категорій в один загальний список.
