# Лабораторна робота №6: Управління правами доступу (DCL) та робота з JSON у SQL

**База даних:** `Scented_candles_diffusers`  
**СУБД:**  MySQL  
**Інструмент:** DBeaver

---

## Мета роботи
* Опанувати основи адміністрування баз даних за допомогою команд мови управління даними (DCL): створення облікових записів користувачів (`CREATE USER`) та розмежування прав доступу (`GRANT`).
* Реалізувати принцип мінімальних привілеїв (Principle of Least Privilege) на рівні окремих таблиць.
* Навчитися формувати плоскі та вкладені JSON-структури безпосередньо засобами SQL за допомогою функцій `JSON_OBJECT()` та `JSON_ARRAYAGG()`.
