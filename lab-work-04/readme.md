# Лабораторна робота №4: SQL-артефакти (Views, Procedures, Triggers)

База даних: `Scented_candles_diffusers` (Інтернет-магазин ароматичних свічок та дифузорів).

---

##  Структура каталогу

* `lab_4_procedure.sql` — створення представлення для деталізації замовлень.
* `lab_4_view.sql` — збережена процедура для додавання нового товару.
* `lab_4_trigger.sql` — модифікація таблиці та тригер для фіксації часу оновлення.
* `test_scripts.sql` — скрипти для перевірки працездатності створених об'єктів.
