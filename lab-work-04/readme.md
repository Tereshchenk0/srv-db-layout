# Лабораторна робота №4: SQL-артефакти (Views, Procedures, Triggers)

База даних: `Scented_candles_diffusers` (Інтернет-магазин ароматичних свічок та дифузорів).

---

##  Структура каталогу

* `01_create_view.sql` — створення представлення для деталізації замовлень.
* `02_create_procedure.sql` — збережена процедура для додавання нового товару.
* `03_create_trigger.sql` — модифікація таблиці та тригер для фіксації часу оновлення.
* `04_test_scripts.sql` — скрипти для перевірки працездатності створених об'єктів.
