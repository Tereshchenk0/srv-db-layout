# Лабораторна робота № 5: Транзакції та оптимізація запитів за допомогою індексів

**База даних:** `Scented_candles_diffusers`  
**СУБД:**  MariaDB (DBeaver)

---

## Мета роботи
Опанувати принципи управління транзакціями (`START TRANSACTION`, `COMMIT`, `ROLLBACK`) для забезпечення цілісності даних (ACID), реалізувати атомарну бізнес-операцію та дослідити вплив індексів (`CREATE INDEX`) на план виконання SQL-запитів за допомогою оператора `EXPLAIN`.

---

## Структура директорії `/lab_5/`

* `lab_5_commit.sql` — демонстрація збереження змін за допомогою `COMMIT`.
* `lab_5_rollback.sql` — демонстрація скасування змін за допомогою `ROLLBACK`.
* `lab_5_index.sql` — створення індексу `idx_users_name` для таблиці `Users`.
* `lab_5_complex_transaction.sql` — реалізація атомарної бізнес-транзакції оформлення замовлення (`Orders`, `Order_Items`, `Products`).
* `lab_5_explain_analysis.sql` — порівняльний аналіз планів виконання запиту (`EXPLAIN`) до та після індексації.
