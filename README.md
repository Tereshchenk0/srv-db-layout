# Database Specification (srv-db-layout)

Репозиторій містить концептуальну та логічну модель бази даних, описану за допомогою мови розмітки 

## Інтерактивна документація
Актуальна онлайн-документація та ER-діаграма згенеровані автоматично за допомогою dbdocs.io:
 [Відкрити інтерактивну документацію схеми](https://dbdocs.io/tereshchenko.vira/srv-db-layout)

## Опис предметної області
База даних призначена для управління процесами інтернет-магазину. Вона зберігає дані про клієнтів, каталог продукції, категорії товарів, а також фіксує оформлені замовлення та позиції в них.
